text**Структура сайта (одностраничная с плавным скроллом):**

1. **Hero секция**
   - По центру большой логотип WebRaptor с неоновым свечением
   - Заголовок: WebRaptor
   - Подзаголовок: «Разработка веб-сайтов и приложений»
   - Две большие кнопки: «Смотреть работы» (скролл к секции Работы) и «Связаться»

2. **Секция «Обо мне»**
   - Слева — сдержанная биография (3–4 предложения)
   - Справа — аватар с лёгким свечением
   - Ниже — стек технологий с иконками и hover-эффектом

3. **Секция «Работы»**
   - Используй данные из `data/projects.ts`
   - Responsive сетка карточек (1 кол на мобильных, 2 на планшете, 3 на десктопе)
   - Каждая карточка содержит: изображение, название, короткое описание, стек (теги)
   - При клике на карточку открывается Modal с подробностями проекта

4. **Отзывы под каждым проектом**
   - Под каждой карточкой проекта (и внутри модального окна) добавь блок отзыва.
   - Структура отзыва:
     - Логотип компании/проекта (если есть)
     - Текст отзыва (3–5 предложений)
     - Подпись: Имя + должность
   - Отзывы храни прямо в объектах проектов в `data/projects.ts`
   - Сделай отзывы легко редактируемыми вручную

5. **Секция «Контакт»**
   - Большая кнопка «Оставить заявку», открывающая модальное окно с формой
   - Форма: имя, телефон, сообщение
   - Отправка через API Route `/api/send-to-telegram`
   - Дополнительная кнопка «Написать в Telegram»

**Технические требования:**
- Next.js 16 + TypeScript (strict)
- Tailwind CSS
- Framer Motion для всех анимаций и модальных окон
- next/image для оптимизации изображений
- Мягкое неоновое свечение на акцентах и hover
- Полная адаптивность (мобильные в приоритете)
- Чистый, хорошо структурированный и прокомментированный код
- Никаких ярких цветов — только чёрный, серый и холодное свечение
